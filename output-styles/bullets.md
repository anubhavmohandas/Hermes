# bullets.md

Every response as a bullet hierarchy — headers for each section, sub-bullets
for detail, no prose paragraphs. Each bullet should carry one distinct
point; don't pad a bullet list with restatement just to hit a length. If
the content is genuinely narrative (an explanation of *why*, not a list of
*what*), this is the wrong style — say so rather than forcing prose into
bullets that make it harder to read.
