# Intake — ask before writing (one message, grouped)

**Required**
1. **What piece?** — blog post / LinkedIn-X post / README-landing copy / newsletter / resume-CV / cover letter / portfolio blurb?
2. **Audience + goal** — who reads it, and what should they do or feel after?
3. **Subject** — the topic, project, or (for career pieces) the role + the actual job description.
4. **Voice** — professional / direct / technical / personal? Anything you'd never say?

**Optional**
5. Raw material — notes, past posts, resume draft, project links? (career pieces: real accomplishments only — nothing invented, ever)
6. Length/platform limits?
7. Call to action — subscribe, star, hire, reply?
8. SEO/keywords that must appear?

# Templates

**T1 — Angle finder**
> For [subject] aimed at [audience], propose 3 distinct angles (the obvious one, the contrarian one, the story-driven one). For each: hook line + why it fits the goal [goal].

**T2 — Draft**
> Write the [piece type] on [subject] using angle: [chosen]. Audience: [audience]. Voice: [voice]. Structure: hook → substance (specifics, numbers, examples — no filler claims) → [CTA]. Length: [limit].

**T3 — Career tailor (resume/cover letter only)**
> Tailor these real accomplishments: [material] to this job description: [JD]. Mirror the JD's own vocabulary where honest, quantify impact, cut anything the JD doesn't care about. Flag any gap honestly rather than papering over it — do not invent experience.

**T4 — Tightening pass**
> Edit this draft to be tighter and more concrete without losing voice: cut hedges, replace abstractions with specifics, make every sentence earn its place: [draft]

# Execution

1. **Angle** — T1; user picks.
2. **Draft** — T2 (career pieces: T3 with the real material — invented experience is a hard no).
3. **Tighten** — T4.
4. **Format** — plain text/markdown inline; file output (docx/pdf) via `skills/documents` if asked.
5. **Log** — Mnemos + ReasoningBank per Apollo §2.
6. **Deliver** — the piece + one alternative hook, + offer a revision round.
